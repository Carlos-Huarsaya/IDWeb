Bienvenido a mi portal academico correspondiente al Laboratorio 01 de la asignatura.

Para la realizacion de este laboratorio se a aplicado:

  • Uso del estricto marcado semantico HTML5
  • Separación de clara entre estructura de contenido

Objetivos del Laboratorio 01

Buscamos alcanzar los siguientes objetivos:

  1. Configurar y validar el entorno de desarrollo web profesional (VS Code, Extensiones, Node.js y Git).
  2. Inspeccionar y analizar la estructura de transacciones HTTP (peticiones GET, cabeceras, cuerpo y códigos de estado) mediante Chrome DevTools.
  3. Construir una interfaz web estática accesible y semántica utilizando elementos de HTML5.
