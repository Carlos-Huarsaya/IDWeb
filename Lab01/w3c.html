Estándar W3C: PNG y SVG

Caracteristica PNG (Portable Network Graphics) [W3C Standard] SVG (Scalable Vector Graphics) [W3C Recommendation]
Tipo de Gráfico Rasterizado / Mapa de bits (píxeles). Vectorial (fórmulas matemáticas y coordenadas).
Resolución Fija. Se pixela o borra al ampliarlo. Infinita. No pierde calidad al escalarlo.
Código CSS/HTML Se inserta como archivo externo (img). Se puede incrustar directamente en el HTML como código.
Estilizado con CSS Limitado (solo filtros básicos como opacidad o sombras). Total. Se pueden cambiar colores (fill, stroke) con CSS.
Ideal para... Fotografías, imágenes detalladas y transparencias complejas. Logotipos, iconos, ilustraciones y gráficos interactivos.
